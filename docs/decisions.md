# 결정 기록

결정 사항은 이 파일에 기록한다.
최종 LOSO 결과를 보기 **전에** 확정하는 것을 원칙으로 한다. 결과를 본 뒤 바꾼 항목은 지우지 말고
"변경 이력"에 남기고, 보고서에서 탐색적 분석으로 표시한다.

## 1. 공통

| 항목 | 결정 |
|---|---|
| 데이터 · 라벨 | WESAD 손목 EDA(4 Hz) · BVP(64 Hz), Stress = 1 / Baseline · Amusement = 0 |
| 구간 | 60초, 겹침 없음 |
| 평가 | LOSO 15-fold, 참가자별 Macro-F1 평균 ± SD |
| 내부 fold 수 | 3 (참가자 단위 GroupKFold) |
| seed | 42 |
| 분류 임곗값 | 0.5 |

## 2. 모델

| 항목 | 결정 |
|---|---|
| 모델 구성 | M0 = 수작업 특징 + LR, M1 = 1D-ResNet + Linear, M2 = ResNet + JEPA 사전학습 + Linear |
| M0 LR 설정 | C = 1, class_weight = balanced, max_iter = 2000 (고정) |
| ResNet · JEPA 하이퍼파라미터 | 미정 (탐색은 1~2개로 제한). 코드 기본값: configs/experiments.yaml |
| M1 특징 융합 방식 | 미정 (인코더 동결 후 Linear만 학습할지 여부). 코드 기본값: 함께 학습 (m1.fusion_mode = joint) |
| M0 특징 | 제공 기준 코드를 아직 못 받아 자체 구현 (src/features/handcrafted.py). EDA 11개(수준·기울기·SCR 수/진폭 등), BVP 9개(HR, SDNN, RMSSD, pNN50 등). 제공 코드를 받으면 교체 |
| M1 · M2 입력 정규화 | 학습 참가자 구간의 모달리티별 평균·표준편차 하나로 z-score (구간별 정규화는 EDA 수준 정보를 지우므로 쓰지 않음) |
| M1 · M2 학습 | 고정 epoch, 조기 종료 없음, BCE pos_weight = 학습 자료의 음성/양성 비 |
| M2 사전학습 자료 | 학습 참가자의 손목 기록 전체에서 무작위 60초 crop (라벨 미사용, 평가 참가자 기록은 쓰지 않음) |

## 3. 연구 질문

| RQ | 항목 | 결정 |
|---|---|---|
| RQ1 | 오류 중복 지표 정의, 분모 0 처리 | 미정. 코드 기본값: Jaccard (둘 다 틀린 구간 / 하나라도 틀린 구간), 분모 0이면 NaN |
| RQ2 | 잡음 종류, SNR 2개 값 (약 / 강) | 미정. 코드 기본값: 백색 가우시안, 10 dB / 0 dB (구간별 BVP 전력 기준) |
| RQ2 | 잡음 적용 시점 | BVP 원신호에, 평가 시에만, 재학습 없음, seed 고정 (EDA는 기준) |
| RQ3 | w 후보 집합, 동률 처리 | 후보 0~1, 0.1 간격 (안) / 동률 처리 미정. 코드 기본값: 0.5에 가장 가까운 w |
| RQ3 | 내부 fold의 M2 사전학습 | 코드 기본값: 내부 fold마다 다시 사전학습 (rq3.inner_pretrain = retrain) |
| RQ4 | 앙상블 다양성 확보 방식 | 미정 (seed만 바꿀지, bootstrap을 더할지). 코드 기본값: seed만 (두 번째 seed 43) |
